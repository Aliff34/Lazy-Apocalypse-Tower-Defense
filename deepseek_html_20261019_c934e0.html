Lazy Apocalypse:
Tower Defense

A humorous idle / auto-shooter set in a zombie apocalypse. A lazy streamer sits in a chair, and the weapons and gadgets bolted to that chair shoot down waves of zombies on their own. The player doesn't control movement — instead they assemble a build from parts, upgrade stats during the run, and push as far as possible through an endless sequence of waves. Between runs they upgrade the meta.

The Game in Brief

Core Loop

Three phases that repeat every session — meta, run, and results.

META

Meta — IdleMeta

Equipment, upgrades, chests, tasks, shop, and events. Everything permanent between runs.

RUN

Run — Core

Auto-battle wave after wave. XP earned during the run is spent on stat upgrades that reset after.

END

Death / Exit

Results screen with rewards (coins, chest, followers), revive, x2 for an ad, then an interstitial before returning to meta.

INFO

Wave record unlocks new features, locations, part tiers, and Championship rewards. Your highest wave is the single most important number in the game.

Theme: Viewers gained during a run turn into Followers. The game features "stream highlights", YouTube-style button ranks (Silver / Gold / Diamond / Ruby), the "Bros Only Fitness" gym, and characters like Dead Tony and Maki.

Combat

Auto-battle waves, zombie types, revive, speed-ups, and in-run stat upgrades.

The Run (Main Mode)

The main mode is an endless sequence of waves, and the location scrolls (EndlessScrollingLevel). A boss arrives every N waves. In 0.26 the boss wave has a "kill all" timer; in the old flow it is switched off via SystemRC.

The player stays still in the chair and weapons fire automatically. Some gadgets have active skills on cooldown, triggered manually or through Auto Skill.

Revive & Speed

  • Second Chance: revive once per round, for an ad.
  • Game Speed: x2 / x3 for an ad (AdSpeedUp, from wave 3), or permanently with SpeedyPass.
  • Mobs drop XP ("likes"), coins, and loot. Each wave also gives per-wave bonuses.

Section 10

Chests & Gacha

Chest slots, roulettes, the Super Box, and every way to gamble for parts.

CHEST

Chest slots with an opening timer, speed-up for gems or ads, and an extra slot for purchase. Chests give parts.

Chest Types

  • Daily — daily free chest.
  • Chapter — chapter milestones.
  • PvE — post-run loot; the first is guaranteed after 2 runs.
  • XP chests — contain XP boosts.
  • Battle Pass — season rewards.
  • Shop — purchasable chests.
  • Leaderboards — ranking rewards.

Gacha & Roulette

  • Gacha Super Box — in the shop, unlocked from wave 20.
  • Mega Roulette (Ad Roulette) — 1 free and 5 ad spins per day, a Mega Chest every 6 spins, bonuses for the total number of spins.
  • Lose-screen roulette — off in the old flow, replaced by x2 coins for an ad.
  • Chest Drop Modifier — modifies chest drop rates.

Section 11

Tasks, Retention & Social

Quests, leaderboards, offline income, ads, and everything that keeps the apocalypse social.

Quests & Login

  • Main Quest — linear achievements that guide the player.
  • Daily and Weekly Quests with progress chests.
  • 7 Days to Survive — a seven-day quest for new players, with a separate version for limited events.
  • 7-Days Login — login rewards, unlocked after the first chapters.

Offline & Ads

  • Offline Radar — offline income. The radar level grows with waves (50, 90, 200), increasing the accumulation hours. From wave 91 the radar also gives CPU.
  • Ad Boosters (AdBuffs) — temporary attack and followers buffs for ads, from wave 30.
  • Quick Ads — ad bonuses (XP before a boss, a temporary pet, event currency).

Leaderboards & Social

  • Leaderboards (server-side) — Followers (global and per tier), Might, event Roulette ranking, World Boss, Championship.
  • Mail — rewards and news, from wave 20.
  • Promo codes — redeemable bonuses.
  • Profile — name, avatar, frame, achievements.

Quality of Life

  • Rate Us — from wave 25: native review dialog or store redirect (InAppReviewRC).
  • Push notifications — MobileNotifications.
  • Calendar "Events schedule" — the full event schedule.

LiveOps Events

Limited-time events, mini events, seasonal rotations, and weekly activities.

Limited Events (7 days)

Six themes: Halloween, Christmas (New Year), Chinese New Year, Hanami (Spring), Rave, Pirates. Each has its own location. From 19.10.2026 the rotation is anchored to holidays; other weeks are filled from a deterministic deck (LimitedEventRotationRC).

Halloween Christmas Chinese New Year Hanami Rave Pirates

Main Mechanic

Roulette for Magic Balls — guaranteed diorama piece every 50–150 spins.

Raffle for Toy Hammers — smash objects on a field; the super prize moves you to the next field, and the last super prize is a unique pet token.

Event Contents

  • Event Pass — progression rewards.
  • Ranking — entry only in the first 6 days.
  • Event shop — spend event currency.
  • Quests — event-specific objectives.
  • Login rewards — daily during the event.
  • Leaderboard — competitive ranking.
BUNDLE

"Buy 1 & get 1 for FREE" bundles and reminder popups. When the event ends, leftover event resources are converted.

Other Events

Mini Events

For Crystals, CPU and Prisms: spend the resource, complete the cycle's quests. There is also a starter variant.

Pet Skin Summon / Costume Party

Thu–Sun, a skin gacha for Costume Coupons with a daily spin limit and quests.

Skins Delivery

Purchases accumulate Fuel for weekly skin rewards.

New Tier Mini Event

Quests when entering a new tier.

Friday Sale Madness

Weekly World Boss event — see Extra Modes (Section 08).
